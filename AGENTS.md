# Development Guidelines

## JS & Runtime
pakai deno sebagai runtime dan package_manager, jangan pakai node,npm/pnpm,etc.

## Terminologi
- SSoT = Single Source of Truth
- copas = Copy + Paste

## Metodologi
- menerapkan polymorphic with anti-pattern for everything.
- menerapkan high-coupling dengan facade-pattern, sehingga menjadi hybrid-loose-coupling.
- menerapkan metode: Observe (Amati), Imitate (Tiru), Modify (Ubah).
